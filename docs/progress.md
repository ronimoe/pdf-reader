## M0: Skeleton (branch `m0-skeleton`)

- **App.** A `ReaderDocument` subclass of `NSDocument` with autosave, drafts and Versions turned off (A1). It keeps the original bytes in memory and builds a `PDFDocument` from them.

- `scripts/test.sh`, a one-command headless test run.
